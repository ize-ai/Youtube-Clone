# YouTube Homepage Clone

A responsive front-end recreation of the YouTube homepage, built to practise turning a real interface into clean HTML and CSS.

> **Educational project.** This is not affiliated with, or endorsed by, YouTube.

![Screenshot of the YouTube homepage clone](screenshot.webp)

**[View the live site](https://aishahyoutube-clone.netlify.app)**

## What it includes

- A header with a logo, search bar and icon buttons
- A sidebar menu (Home, Explore, Subscriptions, Originals, YouTube Music and Library)
- A grid of video cards, each with a thumbnail, duration, channel avatar, title, channel name and view count
- A responsive layout that adapts between mobile and desktop screens

## Built with

- **HTML5**: semantic page structure
- **CSS3**: Flexbox, CSS Grid and media query breakpoints

## What I practised

- Breaking a busy interface down into smaller, reusable pieces
- Using Flexbox for alignment and Grid for the video layout
- Adjusting the layout at different breakpoints so it works on phones and larger screens
- Keeping spacing and sizing consistent across the page

## Run it locally

There's no build step. Clone the repo and open `index.html` in your browser:

```bash
git clone https://github.com/ize-ai/Youtube-Clone.git
cd Youtube-Clone
```

Then open `index.html`, or use the Live Server extension in VS Code.

## Project structure

```
Youtube-Clone/
├── index.html          # page markup
├── youtube styles/     # CSS files
├── thumbnails/         # video thumbnails
├── Channel-pictures/   # channel avatars
└── Icons/              # interface icons
```
